# CNC Machining & Threading Hub

Веб-комплекс инженерных калькуляторов и генераторов управляющих программ (G-код Fanuc) для операторов и наладчиков токарных автоматов продольного точения (Swiss-type) и фрезерных станков с ЧПУ.

🌐 **Тестовая онлайн-версия:** [https://popsalupa.github.io/CalcFask/](https://popsalupa.github.io/CalcFask/)

---

## Реализованные модули

### 1. Вид 01: Сферический купол (`radType1`)
* **Оптимизированный чистовой G-код:** Компактный цикл обработки без лишних отходов и промежуточных перемещений:
  * Быстрый подвод: `G00 X(D+0.5) Z0.`
  * Торцевание и гарантированный срез центрального «пупка» с учетом радиуса вершины пластины (квадрант T3 в диаметральном выражении): `G01 X(-2·r)`
  * Непрерывная чистовая обточка сферы: `G02 X... Z... R...`
* **Коррекция пластины (T3):** Опциональное поле ввода без лишних чекбоксов. Если поле пустое — расчет идет по теоретическому контуру; при вводе радиуса (напр. `0.2` или `0.4`) автоматически рассчитывается эквидистанта инструмента.
* **Строгая фиксация выхода на диаметр:** Конечная точка дуги по $X$ строго равна номинальному диаметру детали $D$, а координата $Z$ рассчитывается через уравнение дуги эквидистанты ($Z_{prog} = z_{tc} - r$).
* **Обработка кромки B (выход на цилиндр):**
  * Двухпозиционный компактный свитч: **`[ G1 | G2/3 ]`** (фаска или радиусное скругление).
  * Корректный расчет микрофаски `G1` через опорные точки сопряжения $B_1$ и $B_2$, исключающий провалы по диаметру и реверсивные ходы инструмента.
* **Динамический SVG-чертеж:** Мгновенное обновление графики при переключении режимов со сглаженными сопряжениями кромок.

### 2. Резьбофреза Swiss PRO (`rezFreza`)
* Расчет траекторий резьбофрезерования для внутренних/наружных резьб и глухих/сквозных отверстий.
* Поддержка радиального, дугового (90°) и линейного (45°) врезания/выхода.
* Интерактивная векторная схема инструмента и профиля резьбы с крупным масштабированием.
* Очищены конфликтующие CSS-стили, устранены пунктирные рамки у необязательных параметров.
* Интегрирован асинхронный таймер со случайным интервалом для динамической смены плейсхолдера.

### 3. Базовые фаски (Передняя и задняя)
* Расчет конических фасок, углов и контрольных точек пересечений.
* Режимы вывода: координаты опорных точек (`Point`) и готовый G-код (`Program`).
* Устранены конфликты абсолютного позиционирования интерфейсных элементов в окне чертежа.

### 4. Хаб радиусов и скруглений (`radHub`)
* Главное навигационное меню по всем типам радиусных сопряжений детали.
* Двухколоночная адаптивная сетка карточек с крупными окнами предварительного просмотра геометрии.

## Интерфейс и адаптивность (ПК / Mobile)

* **Единый темный UI:** Профессиональная цветовая схема для цеховых сенсорных панелей и мониторов (`#0b0f17`, `#141c28`, акцентный циан `#38bdf8` и индикация `#f43f5e`).
* **Адаптивность для экранов ПК (`@media min-width: 768px`):**
  * Рабочая область калькуляторов расширена до 640–760px.
  * Высота окон чертежей увеличена до 220–260px, что обеспечивает комфортное чтение размеров без необходимости ручного масштабирования страницы.
  * Сетки параметров 2x2 перестроены с увеличенными шрифтами и отступами под управление мышью.

## Стек технологий

* **Frontend:** HTML5, CSS3 (Grid, Flexbox, Media Queries).
* **Графика:** Чистый inline SVG без сторонних библиотек.
* **Математика:** Vanilla JavaScript (аналитическая геометрия, тригонометрические сопряжения, расчет эквидистант инструмента).
* **Совместимость G-кода:** Fanuc, Mitsubishi, Haas (стандарт ISO/EIA).
