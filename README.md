# CNC Machining & Threading Hub

Веб-комплекс инженерных калькуляторов и генераторов управляющих программ (G-код Fanuc) для операторов и наладчиков токарных автоматов продольного точения (Swiss-type) и токарно-фрезерных обрабатывающих центров с ЧПУ.

🌐 **Тестовая онлайн-версия:** [https://popsalupa.github.io/CalcFask/](https://popsalupa.github.io/CalcFask/)

---

## Реализованные модули

### 1. Наружные радиусы и сопряжения

#### Вид 01: Сферический купол (`radType1`)
* Чистовая обработка выпуклых сферических торцев с гарантированным срезом центрального выступа пластиной (квадрант T3): `G01 X(-2·r)`.
* Опциональная коррекция вершины резца $r$ (T3) с автоматическим пересчетом эквидистанты контура.
* Обработка кромки B (выход на наружный диаметр): переключатель микрофаски `G1` или радиусного сопряжения `G2/G3`.
* Динамический SVG-чертеж со сглаженным перестроением геометрии.

#### Вид 02: Наружный радиус кромки (`radType2`)
* **Гибкий расчет геометрии (3 из 4):** Возможность задать любые три параметра из четырех ($D_1$ детали, $d_2$ начала, $R_1$ радиус, $L_1$ длина по $Z$) с вычислением недостающего по кнопке-счётам `🧮`.
* **Эстетичный блок верхних опций:**
  * **Пластина $r$ (T3):** активация компенсации вершины резца через чекбокс (без компенсации при отключении).
  * **Микроскругление $R_2$ на торце:** активация плавного двухдугового сопряжения через чекбокс.
* **Сглаженная векторная графика:** Аналитическое построение дуг SVG без ступенек и искажений с автоматической сменой контрольных точек:
  * В базовом режиме: точки **A** (торец) и **B** (цилиндр).
  * С включенным $R_2$: точки **A** (торец), **B** (касание дуг $R_2 \to R_1$) и **C** (выход на диаметр $D_1$).
* **Компактный чистовой G-код Fanuc:**
  * Базовый контур (3 строки): `G00 X... Z1` $\to$ `G01 Z0 F0.1` $\to$ `G03 X(D1) Z-(L1) R(R1) F0.04`.
  * Двухдуговой контур с $R_2$ (4 строки): подвод, касание торца и две последовательные интерполяции `G03` с эквидистантой инструмента.
* **Режимы отображения:** переключение между готовой УП (`Program`) и координатами расчетных опорных точек (`Point`).

### 2. Фаски и отрезка

#### Базовая передняя фаска (`frFasc` / Type 1)
* Расчет входных конических фасок, углов и контрольных точек сопряжения.
* Автоматический расчет недостающих размеров (3 из 4 параметров).
* Коррекция на радиус пластины по $X$ и $Z$, генерация чистового перехода.

#### Задняя фаска под отрезку (`rrFasc` / Type 2)
* Расчет геометрических параметров обратной фаски с учетом толщины отрезного резца $W$.
* Опциональные микроэлементы $R_1$ (вход) и $R_2$ (выход в плоскость отрезки) в режимах фаски `G1` или дуги `G2/G3`.
* Вывод опорных координат и управляющей программы.

---

### 3. Резьбофрезерование

#### Резьбофреза Swiss PRO (`rezFreza`)
* Винтовая интерполяция для внутренней и наружной резьбы.
* Расчет минутной подачи центра инструмента с учетом коррекции на диаметр фрезы и резьбы.
* Радиальное, дуговое (90°) и тангенциальное (45°) врезание/выход.
* Интерактивная схема инструмента с визуализацией ниток резьбы.

---

### 4. Навигационный хаб радиусов (`radHub`)
* Единое меню выбора типовых радиусных сопряжений детали.
* Двухколоночная адаптивная сетка карточек базовых видов (1–4) и сложных контурных сопряжений.
* Прямой роутинг с главной страницы без промежуточных модальных окон-заглушек.

## Архитектура интерфейса и стилей

* **Единый темный UI:** Профессиональная цветовая палитра для цеховых мониторов и сенсорных панелей (`#0b0f17`, `#141c28`, акцентный циан `#38bdf8`, теплый янтарь `#f59e0b` и сигнальный `#f43f5e`).
* **Модульный CSS (`radHub.css`, `radType.css`):**
  * Полноценная адаптивность для мобильных экранов (до 440px) и ПК/планшетов (`@media min-width: 768px`).
  * Увеличенная высота окон чертежей (до 230px) и комфортные сетки ввода 2x2.
  * Единый стиль полей ввода без вложенных двойных рамок и системных кнопок.
* **Анимация загрузки:** Встроенный векторный прелоадер токарной обработки (шпиндель, деталь, стружка, искры) на страницах модулей.

---

## Стек технологий

* **Разметка и стили:** Семантический HTML5, чистый CSS3 (Grid, Flexbox, Media Queries, CSS Keyframes).
* **Графика:** Inline SVG с динамическим пересчетом путей `path d="..."` в реальном времени.
* **Математический аппарат:** Аналитическая геометрия, тригонометрия сопряжений окружностей и расчет эквидистант инструмента квадранта T3 на чистом Vanilla JS.
* **Формат управляющих программ:** Стандарт ISO/EIA (системы ЧПУ Fanuc, Mitsubishi, Haas, Citizen, Star).
