# ⚙️ CNC Machining & Threading Hub

Веб-приложение для операторов, наладчиков и технологов-программистов станков с ЧПУ (токарная группа, автоматы продольного точения Swiss-type и фрезерные ОЦ: Fanuc, Siemens, HAAS, Heidenhain).
https://popsalupa.github.io/CalcFask/

Хаб объединяет инженерные калькуляторы геометрических сопряжений, компенсации вершины режущего инструмента, резьбофрезерования, режимов резания и генерации готовых фрагментов управляющих программ (G-код).

---

## 🚀 Основные возможности

* **Инженерный UI/UX:** Темная тема в индустриальном стиле, векторный Favicon твердосплавной пластины, анимированный прелоадер токарной обработки в реальном времени, интерактивные SVG-чертежи с размерными линиями параметров деталей и инструментов, мобильная адаптация (`inputmode="decimal"`) с автозаменой запятых на точки.
* **Модуль № 01 — Передняя фаска (`frFasc`):**
  * Взаимный расчет геометрии «3 из 4 параметров» (D1, d2, Angle 1, L1).
  * Аналитический расчет эквидистанты вершины пластины ($R$) по квадранту T3.
  * Тангенциальные сопряжения дугами ($G02/G03$) и микрофасками ($G01$) на торце и переходе к цилиндру.
* **Модуль № 02 — Задняя фаска (`rrFasc`):**
  * Расчет конуса под отрезку от большего диаметра к меньшему.
  * Учет ширины отрезной пластины ($W$) и безопасного диаметра подхода (БП).
  * Автоматический пересчет длины врезания ($l_2$) и вылета к плоскости отрезки.
* **Модуль № 05 — Резьбофрезерование (`rezFreza`):**
  * Генерация УП для токарных автоматов продольного точения (Swiss-type) с интерполяцией по оси C и Z (`H` / `W` для стоек Fanuc) и классических фрезерных 3-осевых станков ($G02/G03$).
  * 3 стратегии врезания и выхода: **радиальное** (прямой врез по X), **тангенциально-дуговое** (плавный полукруг/четверть круга с подъемом по Z) и **тангенциально-линейное** (подвод по касательной 45°).
  * Нарезание внутренней и наружной резьбы, переключение оси X (диаметр $\varnothing$ / радиус $R$).
  * Автоматический расчет диаметра отверстия под резьбу ($D - P$) и пошаговая разбивка припуска на черновые и чистовые проходы.
  * Учет длины рабочей части гребенки ($L_{cut}$) для работы за один виток или непрерывную многовитковую спираль.
  * Автоматический пересчет подачи центра оси фрезы ($F_{center}$) для исключения сколов зубьев при внутреннем фрезеровании.
* **Генератор чистового G-кода:** Формирование выверенных кадров перемещений Fanuc (автоматическая расстановка точек у целочисленных координат), русскоязычные комментарии к траекториям, быстрый экспорт в буфер обмена.
